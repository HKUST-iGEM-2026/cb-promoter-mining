\section*{Method}
Restricted scan + tailored null. Candidates are the 175,911 upstream-of-gene windows; the null is the 1,726 convergent-intergenic samples (both strands of the 81 bp negatives). Both are intergenic + AT-rich, so the empirical p is a composition-matched comparison. Ensemble = mean rank-percentile pooled over the RESTRICTED candidates + null (calibration-free).

\section*{Null score distribution (ensemble rank-percentile)}
median 0.6135, p95 0.8911, p99 0.9526, max 0.9944.
Smallest achievable p-value $= 1/(N_{\mathrm{null}}+1) = \num{5.79e-04}$
($N_{\mathrm{null}} = 1,726$).

\section*{Discoveries}
\begin{itemize}
  \item candidate windows tested: 175,911
  \item windows passing empirical $p \le 0.05$: peak-called into \textbf{3,358 promoter loci}
  \item loci at $q \le 0.05$: \textbf{3,358}; at $q \le 0.10$: 3,358
  \item reported: top 80 by ensemble score (0 summit windows truncated at a contig end)
  \item top-80 ensemble range $[0.9964, 0.9994]$, $q$ range $[\num{1.01e-02}, \num{1.01e-02}]$
\end{itemize}
