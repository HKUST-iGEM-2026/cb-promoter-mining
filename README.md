# Genome Mining Project for Clostridium Butyricum DSM 10702 Strain

This project uses 2 fine-tuned genomic language models ([ProkBERT-mini-long](https://github.com/nbrg-ppcu/prokbert) and [Nucleotide Transformer](https://github.com/instadeepai/nucleotide-transformer)), in addition to a custom trained CNN for genomic minimg of Clostridium Butyricum to discover new and novel parts (only promoter for now) as well as their strengths.
