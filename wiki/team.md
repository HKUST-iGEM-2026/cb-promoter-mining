# Team

> **Standard URL:** `2026.igem.wiki/hkust/team`

We are the HKUST iGEM 2026 team. Our project has a computational **dry lab** (promoter mining) and an
experimental **wet lab** (validation and chassis work).

## Dry lab — Promoter Mining

A nine-person team building the computational pipeline. Roles below reflect primary areas of ownership.

| Member | Primary contributions |
|---|---|
| **Oak** *(dry-lab lead)* | Project lead; infrastructure & HPC access; in-genus TSS data; hyperparameter sweep; final candidate table & roadmap |
| **Swasti** | Workflow scaffold & cluster setup; software environments; pipeline validation; genome mining |
| **Sine** | Model fine-tuning loop; TSS re-processing; housekeeping-gene set; dataset clustering & splits |
| **Seonyu** | Metrics & cross-validation; calibration/FDR harness; operon detection; upstream extraction; negative-set generation |
| **Salimah** | *Clostridium* genome collection; dRNA-seq/TSS literature search; synthetic-promoter curation; ensemble aggregation |
| **Leo** | Genome re-annotation; curated-promoter normalization; per-model tokenization; motif annotation |
| **Sanaa** | Fine-tuning recipe; ProkBERT and Nucleotide-Transformer training; hyperparameter sweep |
| **Ishi** | Sliding-window inference; calibration; empirical FDR; peak calling; final candidate output |
| **Yany** | Custom CNN (from scratch) and fusion CNN; metrics suite; cross-validation; external holdout evaluation |
